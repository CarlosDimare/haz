Store a memory about the current project that Ojito will remember across sessions. Use this PROACTIVELY whenever the user shares important information about the project: technical decisions, preferences, patterns, constraints, or anything worth recalling later. Do not wait for the user to ask you to remember — if it seems important, save it. Memories are automatically included in the system prompt on every conversation turn. To list stored memories, call this tool with no arguments. To remove a memory, use the olvidar tool.
